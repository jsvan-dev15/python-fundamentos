## ✅ Conteúdos já concluídos

- **Condicionais**: `if`, `elif`, `else`, operadores relacionais e lógicos
- **Laços de repetição**: `while`, `for`, `range()`, `break`, `continue`
- **Listas**: criação, `append()`, `remove()`, `pop()`, `sort()`, percorrer com `for`
- **Tuplas**: criação, índices, `count()`, `index()`
- **Dicionários**: acesso por chave, `.items()`, `update()`
